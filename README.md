# REPO

## República de PROPIETARIOS Orgánicos

REPO es un proyecto de reconstrucción institucional, económica y social
orientado a una República de propietarios ampliamente distribuidos.

Este repositorio contiene las versiones públicas verificables del proyecto.

## Versión pública

**v1.4**

**Fecha de publicación prevista:** 14 de septiembre de 2026.

## Documento Maestro

La versión pública del Documento Maestro se encuentra en:

`DOCUMENTO-MAESTRO-v1.4.txt`

Esta versión corresponde al contenido congelado internamente como RC19.

## Método

REPO distingue entre hechos verificados, declaraciones atribuidas,
propuestas, inferencias, testimonios, cálculos y asuntos no resueltos.

Una propuesta no debe presentarse como un hecho.

Una declaración interesada no debe presentarse como una verdad objetiva.

Un vacío de información no debe rellenarse con una cifra plausible.

## Verificación

Las versiones públicas de REPO incluyen sumas SHA-256 para permitir
la comprobación independiente de su integridad.

El historial Git permite identificar el estado de los archivos en cada
versión publicada.

## Investigación y archivos internos

La investigación, los borradores y los materiales internos de trabajo
no forman parte de este repositorio público.

## Licencia

REPO se publica bajo una licencia abierta indicada en los archivos
de distribución.
